# API examples

Register through `POST /api/v1/auth/register` with `{ "email": "learner@example.org", "password": "a-long-example-password", "tenantName": "Practice Co" }`. Create accounts through `POST /api/v1/accounts`. Post a date, description, and at least two lines using positive decimal strings and explicit `DEBIT` or `CREDIT` direction. Amount totals must match.
